🔑
Para envio automático, você precisa se cadastrar no Garmin Connect Developer Program e obter as credenciais OAuth.
PASSOS PARA ATIVAR
1
Cadastre-se em developer.garmin.com e solicite acesso à Training API
2
Adicione seu Client ID e Secret no código do app (variáveis GARMIN_CLIENT_ID e GARMIN_CLIENT_SECRET)
3
Configure um backend (Vercel, Cloudflare Workers) para processar o OAuth com segurança
4
O treino será enviado automaticamente ao calendário do Garmin Connect e sincronizado com o relógio
